# 📊 Challenge Data Science - Alura Store

Hola 👋  

Este proyecto fue realizado como parte del **Challenge de Data Science de Alura Latam**.  
El objetivo es analizar los datos de ventas de 4 tiendas de **Alura Store** para ayudar al Sr. Juan a decidir **qué tienda debería vender** para iniciar un nuevo emprendimiento.

---

# 🎯 Objetivo del proyecto

Analizar diferentes datos de ventas de las tiendas para encontrar cuál tiene **el peor rendimiento** y así recomendar cuál sería la mejor opción para vender.

Para esto se analizaron varios factores como:

- 💰 Ingresos totales de cada tienda
- 🛒 Categorías de productos más vendidas
- ⭐ Calificación promedio de los clientes
- 📦 Productos más y menos vendidos
- 🚚 Costo promedio de envío

---

# 🛠️ Herramientas utilizadas

Para realizar el análisis se utilizaron las siguientes herramientas:

- **Python**
- **Pandas** → para analizar los datos
- **Matplotlib** → para crear gráficos
- **Google Colab** → para desarrollar el proyecto

---

# 📈 Análisis realizados

Durante el proyecto se realizaron diferentes análisis:

### 💰 Ingresos por tienda
Se calcularon los ingresos totales de cada tienda sumando los valores de venta.

### 🛒 Categorías más vendidas
Se analizaron las categorías de productos más populares en cada tienda.

### ⭐ Calificación de los clientes
Se calculó el promedio de calificaciones que los clientes dieron a cada tienda.

### 📦 Productos más vendidos
Se identificaron los productos con más ventas y los menos vendidos.

### 🚚 Costo promedio de envío
Se analizó cuánto se paga en promedio por el envío en cada tienda.

---

# 📊 Visualización de datos

Para entender mejor los resultados se crearon diferentes gráficos como:

- 📊 Gráfico de barras
- 🥧 Gráfico circular
- 📉 Gráfico de dispersión

Estos gráficos ayudan a visualizar mejor el comportamiento de las ventas en cada tienda.

---

# 🧠 Conclusión

Después de analizar todos los datos, se puede identificar cuál tienda tiene el rendimiento más bajo considerando ingresos, ventas y satisfacción de clientes.

Con base en este análisis se puede recomendar al Sr. Juan **qué tienda debería vender** para enfocarse en su nuevo negocio.
